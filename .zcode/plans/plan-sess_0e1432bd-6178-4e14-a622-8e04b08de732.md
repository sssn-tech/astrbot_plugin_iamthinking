## astrbot_plugin_iamthinking v0.2.0 功能增强计划

### 新增功能

**1. 超时/失败处理**
- `on_waiting_llm_request` 中启动 `asyncio.Task` 定时器，等待 `timeout_seconds`（默认 120s，0=禁用）
- `on_llm_response` 触发时取消定时器，走正常流程
- 超时触发时：移除思考表情 → 贴失败表情 → 标记 `iamthinking_timed_out`
- `terminate()` 中清理所有未完成的定时器

**2. 工具调用状态**
- 钩入 `on_using_llm_tool`：处于 THINKING 时，移除思考表情，贴工具调用表情
- 钩入 `on_llm_tool_respond`：移除工具调用表情，重新贴思考表情
- 支持工具多次调用场景

**3. 失败后恢复**
- `after_message_sent` 中检测 `iamthinking_timed_out` 标志
- 若已超时但 LLM 最终响应：移除 error 表情 → 贴 done 表情 → 标记完成

### 新增配置项（_conf_schema.json）

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `timeout_seconds` | int | 120 | 超时阈值秒数，0=禁用 |
| `error_emoji_ids` | list[int] | [264] | 失败表情（捂脸） |
| `remove_thinking_on_error` | bool | true | 超时后是否移除思考表情 |
| `using_tool_emoji_ids` | list[int] | [270] | 工具调用表情（emm） |
| `remove_thinking_on_tool` | bool | true | 切换工具状态时是否移除思考表情 |

### 代码重构

1. **封装 `_transition_state` 方法**：移除旧表情 + 贴新表情
2. **超时任务管理**：`self._timeout_tasks: dict[Any, asyncio.Task]`，按 message_id 索引
3. **状态标志**（event extras）：新增 `iamthinking_timed_out`、`iamthinking_in_tool`
4. **日志增强**：状态转换时记录状态名
